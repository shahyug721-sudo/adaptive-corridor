# Legacy prototype

The original single-junction / Manhattan corridor prototype that preceded the
Samruddhi Mahamarg model. Kept for reference and because the Mock-1 slides cite
its acoustic siren-ID concept.

**These pages do not run.** They were uploaded to GitHub without their `js/`
directory, so `js/sim.js`, `js/city.js`, `js/drive.js`, `js/render3d.js` and
`js/main.js` are all missing and every page 404s on load. Restore them from the
original `corridor-sim` archive if you want this working again.

The current project is at the repository root — see the top-level README.
